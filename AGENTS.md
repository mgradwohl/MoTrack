# MoTrack contributor instructions

- Follow [CONTRIBUTING.md](CONTRIBUTING.md) for C++ conventions, build, and review.
- Follow the [migration plan](docs/migration-plan.md) for architecture and compatibility.
- Use Clang and CMake on Windows, macOS, and Linux. The combined line coverage gate is 90%.
- Keep changes focused. Run formatting, static analysis, and relevant tests before opening a pull request.
- Preserve familiar Tracker workflows and route user-facing text through Qt translation.
